# Intro

Handy [Obsidian](https://obsidian.md/) setups that I think others might benefit from.

Still making stuff presentable!

For now, [big-green "Code" button → Download ZIP → Extract → Open folder as vault] to use one.

# Trackers

## [Art Tracker](/Art%20Tracker/)

![](/src/img/art-tracker.webp)

Track whether or not you drew daily (or almost daily) with art thumbnails, or thumbnails based on what tracker data is missing.

## [Comic Task Tracker](/Comic%20Task%20Tracker/)

![](/src/img/comic-task-tracker.webp)

Track the steps of your comic process for both one-page, and multi-page comics!  
Pairs well with [TaskNotes](https://community.obsidian.md/plugins/tasknotes) and [Tasks](https://community.obsidian.md/plugins/obsidian-tasks-plugin).
